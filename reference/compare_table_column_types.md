# Align the columns of data frames to see where their names and types synch up

Align the columns of data frames to see where their names and types
synch up

## Usage

``` r
compare_table_column_types(...)
```

## Arguments

- ...:

  \<\[\`dynamic-dots\`\]\[rlang::dyn-dots\]\> named data frames to
  compare

## Value

a data frame with column names in "Column" and a column of types for
each argument
